## 下次怎样打开

本机后台通过当前 Windows 用户的启动文件夹，在登录后隐藏启动。它仅监听 127.0.0.1:8765，不会自动启动 SecureCRT 或提交分析。不需要一直开着 Codex；关闭网页后后台仍运行。电脑关机、休眠、尚未登录 Windows 或后台被停止时，网址不可用。

手动启动：双击 `start.cmd`，会启动后台并打开固定网址。启动器防止同一项目重复启动，并在后台进程退出时重启它。后台日志在 `service.log`。请保留当前项目路径和 Python 安装路径。

安装/更新登录启动项：在 PowerShell 执行 `./install_startup.ps1`。只创建当前用户 Startup 文件夹中的 `GWAS Local Console.lnk`。如需取消登录启动，删除该快捷方式即可（不会取消远程分析）。

## 每次提交

1. 选择 TXT/TSV/CSV 表型文件，最大20 MB，文件名使用英文、数字、点、下划线、短横线。文件按原样传给现有 Perl 程序，不自动推断或变更分隔符。
2. 选择 GPall、GPallInd 或 GPallJap。
3. 填写远程目录名称，可以与上一次相同。目录不存在时创建，存在时复用程序；每次均从指定来源重新复制基础基因型、kinship和样本list。
4. 确认“本次标签”，如 `LSH2023_Re-fitting.txt` 自动填 `LSH2023`，可手动修改。填写已有本地日志目录，输出 `表型文件前缀_GWASrun.log`。
5. 可先预览，点击“提交并启动分析”才会启动 SecureCRT、上传和运行。浏览器记住最近的群体、远程目录、本地日志目录，不记住上传文件。

不同年度示例：第一次上传 `LSH2022_Re-fitting.txt`，完成后同目录再上传 `LSH2023_Re-fitting.txt`。

提交文件先传到服务器本批缓存，再在表型提取前复制到 `/data9/home/yzhao/GWAS_IRGSP1.0/<远程目录>/phenotype/<原文件名>`，逐字节校验与缓存一致，并在日志记录 `UPLOAD_READY: <完整路径>`。隔离转换目录通过链接读取这个正式文件；即使后续转换失败，正式目录中的上传文件仍保留。同名已有文件不覆盖。

## 怎样防止处理旧表型

转换在 `.gwas-runs/<运行编号>/convert/` 的空目录执行，共用本目录的 program/tped；不让转换程序先写入包含旧文件的 EMMAx.Data。由这个空目录的转换产物生成并冻结 `manifest.tsv` 和 `traits.txt`。

已核对你提供的转换程序：标签来自表型列名，它只接收“提取后的CSV、群体”两个参数，并没有独立的第三个标签参数。你的输入列名已经带有 LSH2022/LSH2023/SJ2023 等标签，所以默认保留，例如 `GPall_LSH2023_IRGP_days_chr01.tped`，不会变成 `GPall_LSH2023_Re-fitting_LSH2023_IRGP_days_chr01.tped`。

本次标签默认取去掉 `_Re-fitting` 的文件前缀，可以在网页手动修改。如果原始性状未以该标签开头，发布时才补上标签。原始名称与发布名称一并记录在 manifest。原有年份标签不会被自动删除；使用新标签重做时，会同时保留原性状名。例如标签 LSH2023_v2 可得到 GPall_LSH2023_v2_LSH2023_IRGP_days。

第一列必须为 Accession。上传前拒绝重复性状列、危险文件名字符、加标签后重名和过长名称。去掉UTF-8 BOM并将CRLF转换为LF，避免Perl的chomp留下回车进入文件名；数值和列顺序保持不变。

生成的 chr1–chr9 对外统一为 chr01–chr09；每个性状必须恰好有01–12共12条染色体，缺失、超出范围或重复时停止，绝不通过创建空文件凑齐。TPED、TFAM等配套文件及 pheno 通过绝对符号链接发布到共用 EMMAx.Data，链接目标保存在对应批次的 convert 目录，不能删除该目录。

- GWAS：只读本批 manifest，每个性状12个作业，不执行共享目录的全量 ls/ll。
- 绘图：只读本批 traits，每个性状提交一次，输入该性状 chr01.hIBS。按原总程序的顺序调用三个绘图子程序，但任何子程序失败均传播退出码；完整核验 chromosome/性状.png、plot/性状_chr01–12.png、QQplot/性状_QQplot.png 和 QQplot/性状.value 共15个文件。
- peak SNP：旧程序需要扫描目录，因此在本批 final 目录建立仅含本批12条结果的视图，再执行提取和注释。
- 日志检查/移动：仅本批提交清单中记录的脚本日志。历史 ERROR 文件不混入本批检查。
- 已存在同名输入或输出时停止，不覆盖。相同文件名再次提交也停止；不同年份请用不同文件名。

不要在工具运行期间另行手工向同一分析目录提交计算。工具使用 `.gwas-active/owner` 目录锁，防止两次自动分析交错；它无法阻止外部手工程序。

## 完成判定、故障与恢复

每个排队命令写本批退出码；记录每个作业ID，按 `qstat -u yzhao` 跟踪本批所有状态，绝不只检查R。按本批作业ID观察到全部为C即可检查结果文件和本批日志，不要求C记录从队列消失；任何已有非零退出码仍会停止。未观察到C就消失的作业不能自动判定成功。队列查询失败、非零退出码、作业消失180秒仍无完成标记、缺失结果或日志含 error/fatal/segmentation fault/traceback 都会停止。“0 errors”可能误报，需人工核实。监控上限7天，不自动取消作业。

日志和状态位置：
- 本地 `runs/<运行编号>/`：上传、元数据、VBS桥接脚本、终端输出和状态。
- 远程 `.gwas-web/<运行编号>/`：上传缓存、完整run.log、prepare/admin/final.exit。
- 分析目录 `.gwas-runs/<运行编号>/`：manifest.tsv（原性状、新性状、染色体、原TPED文件基名）、traits.txt、提交记录、各阶段.jobs、status/*.exit及隔离工作区。

网页每5秒刷新本地状态。远程日志按字节偏移增量读取，每块最多4096字节，每轮最多4块；阶段结束时分块读完余量。不会重复传输旧日志或一次打印整份日志；每块更新心跳。未同步的数据保留在远程run.log。超过6分钟没有心跳显示“需要处理”，阻止新提交，避免重复计算。

失败后保留目录锁，不自动重试。人工处理：先停止旧SecureCRT脚本并确认该批次排队/运行的作业均已结束，检查阶段nohup进程也已结束，然后将远程 `.gwas-active` 目录改名留档，最后将对应本地 `runs/<编号>/state.txt` 改成UTF-8文本 `failed|Reviewed manually`。新提交使用新的表型文件名和日志名。未提供自动断点续跑，不能重放admin阶段；它有重复提交保护。

## 修改基因型数据源（v4）

网页展开“基因型数据源”，可分别填写版本名、sampleList、TPED 模板、kinship、MAF 模板。模板中的 `{chr}` 会替换为 `01` 至 `12`，来源文件名可以不同，复制到工作目录后统一为所选群体名称。设置按群体保存在当前浏览器，也写入每批元数据及本地日志。源文件必须已放在服务器上，本工具上传的是表型文件。

每次运行都检查全部26个来源文件存在且非空，然后重新复制12个TPED和kinship到tped目录、sampleList到phenotype目录，覆盖对应旧输入。每个文件先复制到临时文件并比较成功后替换，避免复制中断破坏原文件；复制失败则停止分析。MAF不复制，计算时使用本次填写的模板路径。来源配置记录在本批data-source.txt和日志中，不限制复用同一分析目录。请勿在运行中修改来源文件。

TPED变更时，在网页同时重新指定配套MAF、kinship和样本list。需保证TPED基因型列与list及kinship顺序匹配。本流程仍面向水稻12条染色体和原IRGSP参考/注释；更换参考基因组需要另行修改绘图和注释程序。旧批次结果和独立转换文件保持原样，但共享tped及phenotype中的样本list将更新为本次来源。

GWAS和绘图共用提交函数，每次成功取得qsub作业ID后固定等待5秒再继续，原提交脚本内部的1秒等待仍保留。不提供取消间隔的选项。
